# Start screen image credits

cut-outs, CC0 or public domain (D-45). Each original is rasterized, trimmed and resized to 360 px high with
imagemagick (one-off, not part of the media pipeline; alpha kept, metadata stripped):

`magick -background none -density 300 <file>.svg -strip -trim +repage -resize x360 -quality 80 <slug>.webp`
