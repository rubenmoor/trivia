## Model
- **One language for UI and questions (D-96, superseding D-86's two settings).** One tag in the save (`SaveData.language`); a stored save without it = `es` (the family's); an old `{ui, questions}` reads as `ui`.
  - Default for a fresh save: `guessTag()` (under Steam `GetCurrentGameLanguage` mapped by `STEAM_LANGS` in `lib/engine.ts`, else `navigator.language`) matched against `UI_LANGS`: exact tag, language part, `en`, `es`.
  - A fresh save asks once on the first-start language screen (only with ≥2 options); a stored save never.
  - Changeable only on Start (language button top right, decision 157); no Esc menu rows; a UI change reloads the app.
  - Question locale: the language if its pool exists and passes the supply check, else `es` (`localeOf` in `lib/engine.ts`, decision 156); en/de/es-ES play the `es` questions until their pool ships.
  - A game keeps its locale (`GameRow.locale`); a change applies to the next game.
- **Question locales share IDs.** A translated question keeps its `id`; translations live next to it (D-81). Seen counts go by ID across locales (D-82), so a player who switches languages doesn't get the same question again before unseen ones run out.
- **Launch languages (D-78):** `es`, `en`, `de`; question locales `es`, `es-ES`, `en`, `de` (D-107). Later: `zh-Hans`, `ru`, `pt-BR` (milestone 12, on hold).
- **Regions are bundles, not languages (D-39).** Each game draws from `base` + the player's chosen bundles (`colombia` today). A Spanish-speaking player in Mexico can turn Colombia off; a Colombian player playing in English can keep it on.
- **Spanish varieties (D-78, D-107):** two question locales, like the UI.
  - `es` (`es-419`): idiomatic Latin American Spanish, no compromise with Spain; `pool.json`. English-sourced questions reach it by translation; es-sourced ones (≤ batch-8) had their Colombianisms ("bombillo", "crispetas") rewritten via the pipeline (B-13, S4; `plan 64: Spanish variety (neutral Spanish)`, `qgen neutralize`, D-83; the run: masterplan part 11).
  - `es-ES`: Spain's Spanish, its own pool `pool.es-ES.json` (translations of en and es sources); `vosotros` in the UI.
  - `colombia` keeps its Colombian voice; no finer variants, regional flavour via bundles (later `mexico`, `argentina`).
  - Steam store languages: Spanish – Latin America, Spanish – Spain, English, German.
- **Difficulty is per locale.** A question about Colombian geography is difficulty 3 for a Colombian kid and 8 for a German one. Translations are re-rated (15b), and regional questions are rated for their region.
- **Supply:** every filter (language, region) shrinks the pool. The supply check (GF-2) already runs on whatever is available; the content target (16) is set per language with the default region settings.
