## Model
- **Two settings: UI language and question language.** Usually the same, set once on first start (default: the Steam client language) and changeable in the settings screen.
- **Question locales share IDs.** A translated question keeps its `id`; translations live next to it (15b decides the file layout). Burning works by ID, so a player who switches languages doesn't get the same question again.
- **Launch languages (D-78):** `es`, `en`, `de`. Later: `zh-Hans`, `ru`, `pt-BR` (milestone 12, on hold).
- **Regions are bundles, not languages (D-39).** Each game draws from `base` + the player's chosen bundles (`colombia` today). A Spanish-speaking player in Mexico can turn Colombia off; a Colombian player playing in English can keep it on.
- **Spanish varieties (D-78):** two variants.
  - `base` in neutral Latin American Spanish (`es-419`); the ~40 Colombianisms ("bombillo", "crispetas") rewritten via the pipeline (B-13, S4).
  - `es-ES` only where wording differs: regionalisms, `vosotros` in the UI.
  - `colombia` keeps its Colombian voice; no finer variants, regional flavour via bundles (later `mexico`, `argentina`).
  - Steam store languages: Spanish – Latin America, Spanish – Spain, English, German.
- **Difficulty is per locale.** A question about Colombian geography is difficulty 3 for a Colombian kid and 8 for a German one. Translations are re-rated (15b), and regional questions are rated for their region.
- **Supply:** every filter (language, region) shrinks the pool. The supply check (GF-2) already runs on whatever is available; the content target (16) is set per language with the default region settings.
