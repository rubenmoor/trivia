**Status:** stub

Part of the Steam plan ([11](11-steam.md)). Today everything is Spanish with Colombian usage and Colombian references where natural (D-6). A Steam release needs other languages, and possibly a Spanish that isn't only Colombian. This file owns the shared model; the work is split into three sub-plans:

## Model
- **Two settings: UI language and question language.** Usually the same, set once on first start (default: the Steam client language) and changeable in the settings screen.
- **Question locales share IDs.** A translated question keeps its `id`; translations live next to it (15b decides the file layout). Burning works by ID, so a player who switches languages doesn't get the same question again.
- **Regions are tags, not languages.** A question has `region: null` (anyone can know it) or a region (`"co"` for Colombia). Each game draws from "universal + the player's chosen regions". A Spanish-speaking player in Mexico can turn Colombia off; a Colombian player playing in English can keep it on.
- **Spanish varieties:** the pool's wording is Colombian ("bombillo", "crispetas"). For a Spain or Mexico audience that reads as regional but understandable. Options: ship "Español (Colombia)" as is, or rewrite to neutral Spanish with Colombian variants for the family (OQ-31).
- **Difficulty is per locale.** A question about Colombian geography is difficulty 3 for a Colombian kid and 8 for a German one. Translations are re-rated (15b), and regional questions are rated for their region.
- **Supply:** every filter (language, region) shrinks the pool. The supply check (GF-2) already runs on whatever is available; the content target (16) is set per language with the default region settings.
