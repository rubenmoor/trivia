# Task: fact-check questions

Check the facts in each trivia question below with web searches. Check the answer, the wrong answers (they must really be wrong), the hints and the fun fact.

For each question, give a `verdict`:
- "confirmed": the answer is right, the wrong answers are wrong, and the hints and fun fact are true (small rounding is fine).
- "wrong": something is false. Say what in `problem` and give a `correction`.
- "uncertain": sources disagree or you couldn't verify it.

List the URLs you relied on in `sources`. Keep `problem` and `correction` short, in English (corrections to Spanish text in Spanish).
