# Task: revise existing questions

You get trivia questions that are already in the pool, each with the **issues** found by an independent rater, a web fact-check and possibly the gamemaster. Decide for each question:

- `"keep"`: the issues are minor or wrong; leave the question as it is.
- `"revise"`: fix the issues while keeping the question's topic and its answer where possible. The result must follow the house style above completely: four honest options, no giveaways, a real-world superlative, kid-appropriate difficulty (use the calibration examples), a funny description, three hints from vague to strong, a true fun fact, media that fits the rules.
- `"drop"`: the question can't be saved without becoming a different question (e.g. an essential recording that doesn't exist on Wikimedia Commons, a topic that is too heavy). Say why.

Rules:
- The gamemaster's feedback always wins over the rater.
- Fix wrong facts using the fact-check's correction. Don't add new facts you aren't sure of.
- Set `difficulty` to what the question really is for these players after your changes.
- Change only what's needed to fix the listed issues; unchanged fields must be returned exactly as they were. If the only issue is difficulty, change only `difficulty`. Don't polish hints, descriptions or fun facts that have no listed issue.
- `reason`: one short English sentence on what you changed and why (or why you keep or drop it).
- For "keep" and "drop", return the question fields unchanged.
